# PuzliApp

Jelen alkalmazás oktatási segédlet, amely a Kreatív könyvkiadó [*Magyar nyelv és irodalom (anyanyelv) – VI. osztály*](https://manuale.edu.ro/manuale/Clasa%20a%20VI-a/Limba%20si%20literatura%20materna%20maghiara/Tk9SQU5E/A1465.pdf) című tankönyvének illetve a [*Feladatbank (Ábel kiadó, 2. kötet)*](https://hunlang.lett.ubbcluj.ro/sites/default/files/fajlok/Feladatbank_2.pdf) kiegészítőjének készült.

Az  oktatási segédlet az MTA Domus Programja által támogatott tevékenység keretében jött létre. *Pályázatvezető: Kádár Edit. Szerződésszám: 50/3/2024/HTMT*  
A segédlet felhasználási feltételeit a *CC BY-NC-ND 4.0* licensz szabályozza.

A feladatokat adaptálta: *Kádár Edit és Bartalis Boróka*  
Programozás: *Hompoth Szilárd*

_____________________

Az alkalmazás a *LibGDX* keretrendszer segítségével, a *Kotlin* programozási nyelven készült. Futási környezetek: *LWJGL3*, *TeaVM*.  
Projektépítő: *Gradle*.
